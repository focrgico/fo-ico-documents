# Accords collectifs locaux ICO

Accords négociés au niveau ICO (30-40 accords à intégrer progressivement, actuellement en PDF scannés).

## Nommage des fichiers

`accord-[theme]-[annee].md`

Exemples :
- `accord-paie-2024.md`
- `accord-qvct-2026.md`
- `accord-nuit-ide-as-2026.md`

## Ajouter un accord

1. Convertir le PDF scanné en texte (OCR) — scripts `convertisseur_ocr.py` déjà préparés pour les PDFs image.
2. Relire et corriger le texte issu de l'OCR (les erreurs de reconnaissance sont fréquentes sur les scans).
3. Créer le fichier `.md` dans ce dossier.
4. `git add`, `commit`, `push`.
