## Méthodologie appliquée

- Toujours la **version la plus récente** d'un accord quand plusieurs versions existent (avenant intégré dans le résumé de l'accord de base)
- Chaque référence à la **CCN des CLCC** est indiquée explicitement (article correspondant)
- Citations d'**articles/sous-articles** systématiques entre parenthèses — pas de numéro de page tant que le PDF signé correspondant n'est pas confirmé disponible
- Les **DUE** (décisions unilatérales, non négociées) sont signalées clairement comme telles, jamais présentées comme un acquis syndical
