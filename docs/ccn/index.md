| Grille | Valeur au |
|---|---|
| RMAG non-praticien (RMAG 0/1/2) | 1er novembre 2024 |
| RMAG non-praticien (RMAG 3) | 1er janvier 2025 |
| Médecins/pharmaciens/odontologistes spécialistes | 1er juillet 2023 |
| Médecins/pharmaciens/odontologistes (non-spécialistes) | 1er septembre 2024 |
| Praticiens assistants spécialistes | 1er juillet 2023 |
| Consultants CLCC | 1er juillet 2023 |

À vérifier si un avenant plus récent existe pour les grilles praticiens datées de juillet 2023, avant de s'appuyer dessus dans une négociation.
