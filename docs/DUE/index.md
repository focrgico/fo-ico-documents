# DUE — Décisions Unilatérales de l'Employeur

Contrairement aux accords, une DUE n'est pas négociée ni cosignée par les organisations syndicales — c'est une décision prise unilatéralement par la Direction (signée par le seul Directeur Général). Elle est classée ici séparément des accords pour cette raison.
