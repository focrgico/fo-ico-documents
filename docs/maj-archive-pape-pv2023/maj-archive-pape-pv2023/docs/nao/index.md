## Nommage des fichiers

Le nom du fichier `.md` reprend exactement le nom du PDF signé correspondant (mêmes espaces, majuscules — mais accents retirés, pour éviter un problème d'encodage constaté sous Windows), quand un PDF existe. Sinon, garder un nom clair de type `accord-methode-nao-[annee].md` ou `pv-desaccord-nao-[annee].md`.
